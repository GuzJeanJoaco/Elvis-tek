# Etiquetas relevantes



- `<!DOCTYPE html>`: Etiqueta principal, indica que es una pagina de tipo HTML.

- `<html>... </html> `: Almacena todo el contenido de la pagina. Iclyendo lo visual y los meadatos. Se utiliza la etiqueta `lang`para indicar el lenguaje de la pagina.

- `<title>... </title>`: Se usa para ponerle el titulo a la pagina 


- `<body>...</body>`: Se usa para mostrar todo el contenido visible en la pagina 

- `<head>...</head>`: Esta etiqueta es la que se encarga de guardar los metadatos, y toda la informacion de la pagina. Se coloca antes del `<body>` 

- `<h1>...</h1>`: Se usa para poner el titulo principal o encabezado de la pagina, y definirle el tamaño

- `<img>`_ Se utiliza para insertar imagenes (PNG, JPG, GIF )

- `<src>` : Sirve para poner la URL de la imagen 

- `<alt>`: Sirve para ponerle un texto alternativo a las imagenes 

- `<sections>`: Sirve para separar secciones como las de ¿Quiénes somos?" ."Servicios" o "Contacto"

- `<p>` Se usa para definir parrafos de texto

- `<article>`: Sirve un contenido independiente, como una reseña de un cliente.

- `<a>`: Sirve para crear enlaces.

- `<input>`: Para que los usuarios ingresen datos como  texto, contraseñas, numeros, fechas y opciones.

- `<label>`: Sirve para definir descripciones de elementos de formularios.

- `<table>`: Para organizar informacion en filas y columnas usando etiquetas como `<tr>` para las filas, `<th>` encabezado y `<td>` datos.

- `<option>` : Es para definir elementos individuales dentro de un menú desplegable como `<select>` o una lista de sugerencias como `<datalist>`. `<option>` suele tener un atributo `value` para enviar datos, y el texto interno es lo que visualiza el usuario. 

- `<button>`:Se crean utilizando la etiqueta `<button>`, la cual permite añadir texto e interactividad a sitios web.

- `<select>`:Crea un menú desplegable o lista de selección en formularios para que los usuarios elijan una o varias opciones.

- `<main>`:Define el contenido principal, único y central de un documento o aplicación, excluyendo elementos repetitivos como menús o pies de página.
